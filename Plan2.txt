行，你把 `config/` 和 `utils/` 写完了，至少说明你已经把“把项目开头收拾干净”这件人类罕见的美德做到了。接下来别再在周边打转了，该写能产出结果的主链路了。

## 下一步该写哪些 directory（明确答案）

按 **最短闭环** 来走，下一步就写这四个（按顺序）：

1. **`data/`**
2. **`factors/`**
3. **`portfolio/` + `backtest/`（一起写，先做最简策略）**
4. **`metrics/`（最后补评价）**

`viz/`、`ml/`、`exec_sim/` 全部先别碰。v0 不需要它们，你现在碰就是在给未来挖坑。

---

## 1 `data/` 结构和要完成的东西

### 目标

把“价格数据”读进来，变成全项目统一格式，让后面因子/回测不关心数据从哪来。

### v0 推荐结构（最小但不寒酸）

```
alpha_lab/data/
  __init__.py
  types.py          # 统一的数据结构类型约定（比如 PricesFrame）
  loader.py         # load_prices(), load_returns(), load_universe()
  sources/
    __init__.py
    csv_source.py   # v0 只做 CSV/Parquet 其中一种就行
  clean.py          # 对齐日期、缺失值处理（v0 简化）
```

### v0 必须实现的接口（概念上）

* `load_prices(universe, start, end, field="close") -> DataFrame`

  * index = date（DatetimeIndex）
  * columns = asset（ticker）
  * values = price（float）
* `load_universe(name_or_list) -> list[str]`

  * 可以直接读你 config 里定义的 universe
* 可选：`to_returns(prices) -> DataFrame`

### v0 边界（别膨胀）

* 数据源：**本地 CSV 或 Parquet** 就够
* 不做：复权、停牌处理、行业分类、基本面（先别把自己写死）

---

## 2 `factors/` 结构和要完成的东西

### 目标

输入统一的 prices，输出统一的 factor 值（同样按 date×asset）。

### v0 推荐结构

```
alpha_lab/factors/
  __init__.py
  base.py          # Factor 接口/基类（可选，但建议有）
  momentum.py      # v0 至少 1 个因子：动量
  transforms.py    # winsorize/zscore/rank（v0 可简化）
```

### v0 必须做的因子（选一个就够）

* **Momentum（动量）**：`price[t] / price[t-L] - 1` 或 rolling return
* 输出：`factor_df`（index=date, columns=asset）

### v0 关键纪律

* **shift 一下**：避免用到未来数据（哪怕只是 `shift(1)`，先养成习惯）

---

## 3) `portfolio/` + `backtest/`（一起写）结构和要完成的东西

你要先把“从因子到权重”以及“从权重到 PnL”打通。这俩天然耦合，别拆太细。

---

### 3.1 `portfolio/`（v0 只需要一个简单策略）

#### 目标

把因子分数变成目标权重。

#### v0 推荐结构

```
alpha_lab/portfolio/
  __init__.py
  signals.py       # factor -> signal/rank
  weighting.py     # signal -> weights（等权 top/bottom）
  rebalance.py     # 生成调仓日期（按月/按周）
```

#### v0 策略建议（别搞复杂）

* 每月调仓一次
* 按动量排序：

  * 做多 top K%
  * （可选）做空 bottom K% 或只做多
* 目标权重等权分配

输出格式：

* `weights_df`: index=date(调仓日), columns=asset, values=weight

---

### 3.2 `backtest/`

#### 目标

把 weights + prices 变成 equity curve（净值曲线）和持仓变化。

#### v0 推荐结构

```
alpha_lab/backtest/
  __init__.py
  engine.py        # 主循环：按日期推进、更新持仓、计算 PnL
  account.py       # 账户状态：cash/positions/equity（v0 可简化）
  execution.py     # 成交模型（v0 就 “按收盘价成交”）
  records.py       # 保存 positions/equity/trades（v0 trades 可选）
```

#### v0 的回测模型要多简单？

简单到离谱也行，只要一致：

* 调仓日用收盘价成交
* 不考虑手续费、不考虑滑点
* 每天按持仓计算组合收益，累乘成净值

输出至少要有：

* `equity_curve: Series(date -> equity)`
* `positions: DataFrame(date -> asset weights)`（可选但强烈建议）

## 4 `metrics/` 结构和要完成的东西

### 目标

给 v0 一个“最基本的体检报告”。

### v0 推荐结构

```
alpha_lab/metrics/
  __init__.py
  performance.py   # CAGR, vol, Sharpe（简单版）
  drawdown.py      # max drawdown
  summary.py       # 汇总成 dict / DataFrame
```

### v0 指标最低配（够用）

* 总收益、年化收益（CAGR）
* 年化波动率
* Sharpe（假设无风险利率=0，先别纠结）
* 最大回撤

# 写到什么时候算 v0 完成（明确验收标准）

当你做到下面这些，就叫 **v0 完成**，可以立刻进入 v1（成本、严肃切分等）：

## v0 完成的“硬标准”

1. **能一键跑通端到端流程**（比如一个脚本或 notebook）：

   * 读取 `config`（universe、start/end、rebalance 频率、lookback）
   * `data.load_prices()`
   * `factors.momentum()`（至少一个因子）
   * `portfolio` 生成 weights（按月、top K%）
   * `backtest` 生成 `equity_curve`
   * `metrics` 输出关键指标（dict 或表格）

2. **结果可视化（最低配）**

   * 画出 equity curve（用 `matplotlib` 就行）

3. **没有“明显作弊”**

   * 因子/信号至少有 `shift(1)` 或明确只用历史数据
   * 调仓逻辑清楚：调仓日用哪天价格成交（别含糊）

## v0 允许“先不做”的清单

* 手续费、滑点、冲击成本
* 行业/风格约束
* 风险模型、协方差估计
* walk-forward、train/valid/test
* ML、执行仿真、复杂报表

---

## 最推荐的写作顺序（再给你一次明确路线）

1. `data/loader.py` 跑通：能拿到 close price panel
2. `factors/momentum.py` 跑通：能输出 factor panel
3. `portfolio/weighting.py` 跑通：能在调仓日输出 weights
4. `backtest/engine.py` 跑通：能输出 equity curve
5. `metrics/summary.py` 补齐：能打印指标 + 画曲线

你照这个写，v0 会非常快进入“能跑”的状态。接下来你才有资格谈 v1 的成本和严肃评估，不然都是空谈。
